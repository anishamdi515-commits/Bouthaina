# بثينة 🌸

دفتر حصص بثينة: يسجّل الحصص تلقائياً حسب الجدول، ويحسب الساعات لكل شهر وللسنة الدراسية.

- **تسجيل تلقائي** حسب الجدول (أسبوع واحد أو دورة من عدة أسابيع)، ابتداءً من 1 أكتوبر 2026.
- **الإلغاء بسبب**: الحصة الملغاة تبقى ظاهرة مع سببها ولا تُحتسب.
- **العطل وإيقاف العدّ**: فترة محددة أو «حتى أستأنف بنفسي».
- **التعويضات والساعات الإضافية** في قسم خاص بها.
- **أكثر من عمل**: لكل عمل جدول منفصل ولونه وسعر ساعته.
- **التعلّم**: تعمّر أسبوعاً بأسبوع، والتطبيق يكتشف الدورة ويقترح تكرارها.
- **تغيير الجدول من تاريخ معيّن** دون المساس بالأشهر السابقة.
- **الأجر** (اختياري) وفترة الشهر قابلة للتغيير (من 1 إلى آخر الشهر أو من يوم لآخر).
- **ملف PDF** لأي فترة.
- **واجهة حيّة** حسب الطقس الحقيقي في مكانها (مطر، شمس، ثلج، ليل…) وحسب الفصل.
- **حساب بالبريد الإلكتروني**: البيانات محفوظة في السحابة (Firebase) وتعمل بدون إنترنت.

## التثبيت على الهاتف

**iPhone:** افتحي الرابط في **Safari**، ثم زر المشاركة ⬆️، ثم **إضافة إلى الشاشة الرئيسية**.
**Android:** افتحي الرابط في **Chrome**، ثم ⋮، ثم **تثبيت التطبيق**.

## للمطوّر

```bash
npm install
npm run dev        # http://localhost:5173/bothaina/  (أضف ?demo للتجربة بدون Firebase)
npm test           # اختبارات التواريخ والجداول
npm run build
```

- النشر تلقائي على GitHub Pages عند كل `push` إلى `main` (`.github/workflows/deploy.yml`).
- قواعد الأمان في `firestore.rules`، تُلصق في Firebase Console ← Firestore ← Rules.
- الأيقونات: `node scripts/make-icons.mjs` (تحتاج Playwright).
